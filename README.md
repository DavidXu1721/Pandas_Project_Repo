# Python Data Analysis | Data Technician Bootcamp

## Project Overview

This project was completed as part of a **Data Technician Bootcamp**, focusing on developing practical Python skills for data exploration, cleaning, manipulation, analysis and visualisation.

Using **pandas, NumPy, matplotlib and seaborn**, I worked with retail sales, vehicle fuel efficiency and global GDP datasets to transform raw data, perform calculations, identify patterns and present meaningful insights.

## Key Skills Demonstrated

- **Data Exploration:** Created and inspected pandas DataFrames using `head()`, `tail()`, `shape`, `info()`, `describe()` and `value_counts()` to understand data structure and distributions.
- **Data Filtering and Selection:** Applied Boolean conditions and `.loc[]` to select relevant records, compare values and investigate specific subsets of data.
- **Data Cleaning:** Converted text-based prices into numerical values, renamed columns, identified missing data using `isnull()`, and used `fillna()` to handle missing estimates.
- **Data Manipulation:** Used `groupby()`, `sort_values()`, `nlargest()` and `nsmallest()` to aggregate, rank and compare data across categories.
- **Retail Sales Analysis:** Calculated total revenue from product prices and units sold, rounded results, and exported processed datasets to CSV and Excel.
- **Statistical Analysis:** Applied summary statistics, correlation analysis and the Interquartile Range (IQR) method to investigate relationships and identify outliers.
- **Data Visualisation:** Created histograms, bar charts, scatter plots, box plots and correlation heatmaps using pandas, matplotlib and seaborn.

## Practical Applications

### Retail Sales Analysis
Created a structured sales DataFrame containing product information, prices and units sold. Cleaned currency values, calculated revenue for individual products and exported the results for reporting.

### Vehicle Fuel Efficiency Analysis
Explored vehicle mileage data using conditional filtering, sorting and correlation analysis. Calculated average fuel efficiency, converted mileage measurements and compared vehicles based on fuel consumption.

### Global GDP Data Analysis
Analysed GDP-per-capita estimates from different sources, grouped countries by region, handled missing estimates, and used statistical analysis and visualisations to explore economic differences and outliers.
